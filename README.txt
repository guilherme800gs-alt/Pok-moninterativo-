POKÉMON INTERATIVO — PROJETO ANDROID

O que este projeto faz:
- Instala um papel de parede animado (Live Wallpaper) no Android.
- Mantém a imagem Pokémon como fundo.
- Ao tocar na tela, cria partículas luminosas no ponto tocado.
- Foi configurado com minSdk 23 e targetSdk 35.

IMPORTANTE:
Este pacote contém o PROJETO-FONTE do Android Studio, não um APK já compilado.
Não é possível instalar o arquivo ZIP diretamente no celular.

Como gerar o APK:
1. Em um computador, instale o Android Studio.
2. Extraia este ZIP.
3. No Android Studio, escolha "Open" e selecione a pasta PokemonInterativoAndroid.
4. Aguarde a sincronização do Gradle.
5. Vá em Build > Build Bundle(s) / APK(s) > Build APK(s).
6. O Android Studio mostrará onde salvou o APK.
7. Envie o APK ao Moto G35 e instale. Talvez seja necessário permitir instalação dessa fonte.
8. Abra "Pokémon Interativo", toque em "Escolher papel de parede" e confirme a aplicação na tela inicial.

A imagem de fundo está em:
app/src/main/res/drawable-nodpi/pokemon_wallpaper.jpg
